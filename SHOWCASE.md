# ShareGuard showcase copy

## Portfolio

**ShareGuard** — Privacy-preserving browser screen sharing

Built a Chrome Manifest V3 extension that keeps the presenter’s browser unchanged while producing a separately rendered audience view. ShareGuard selectively redacts passwords, recognizable API tokens and valid payment-card numbers, supports user-drawn blackout regions, and reconnects its scanner as the selected tab navigates between websites.

**Tech:** JavaScript, Chrome Manifest V3, Tab Capture API, Canvas, MediaStream, DOM geometry, Mutation-safe content scripts, Playwright

## Resume bullet

Built **ShareGuard**, a Chrome extension that creates a separate protected screen-sharing stream with real-time redaction of passwords, API tokens and payment-card data, manual blackout controls, and navigation-resilient content-script recovery.

## Short project pitch

Most screen-sharing tools transmit exactly what is on your display. ShareGuard explores a different model: the presenter keeps the normal browser experience while the audience receives a separately rendered, privacy-filtered view.
